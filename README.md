# طاقچه — کلون React

## نصب و اجرا

```bash
npm install
npm run dev
```

## ساختار پروژه

```
src/
├── data/
│   └── index.js          # داده‌ها و ثابت‌ها
├── components/
│   ├── BookCover.jsx      # جلد کتاب
│   ├── BookCard.jsx       # کارت کتاب
│   ├── AudioCard.jsx      # کارت کتاب صوتی
│   ├── Stars.jsx          # ستاره امتیاز
│   ├── SwiperSlider.jsx   # اسلایدر
│   ├── HeroSlider.jsx     # بنر اصلی
│   ├── SectionTitle.jsx   # عنوان بخش
│   ├── Header.jsx         # هدر
│   └── Footer.jsx         # فوتر
├── pages/
│   ├── HomePage.jsx       # صفحه اصلی
│   ├── ProductPage.jsx    # صفحه محصول
│   └── AuthPage.jsx       # ورود / ثبت‌نام
├── App.jsx                # روتر اصلی
├── main.jsx
└── index.css
```
